# 🗡️ C++ Text RPG

> **턴제 던전 탐험 콘솔 RPG**

## 📖 게임 소개
캐릭터 생성부터 몬스터 전투, 상점 이용, 포션 제작을 거쳐 최종 보스(드래곤)를 처치하고 던전을 정복하는 C++ 텍스트 RPG입니다.

---

## 🎮 주요 기능
* **캐릭터 생성:** 이름, 스탯, 직업 선택을 통한 캐릭터 생성
  * **스킬 시스템**: 각 직업은 고유 스킬들을 가지며, 특정 레벨(0, 2, 5, 10)을 달성 시 해금
* **던전 탐험 및 턴제 전투:** 1F~4F 및 보스 방에서의 몬스터와 턴제 전투
  * **전투 보상**: 몬스터 처치 시 골드, 경험치 및 드롭 아이템 획득
  * **던전 해금**: 각 던전은 이전 던전의 목표치(일정 횟수 이상의 몬스터 연속 처치) 달성 시 해금
* **메인 메뉴 내 정비 시스템:**
  * **상점:** 아이템 판매 및 구매
  * **포션 제작소:** 제작 재료를 조합하여 포션 제작
  * **인벤토리:** 소지품 확인 및 정렬 기능 (이름, 개수, 가격, 종류)
* **게임 오버 / 클리어:** 캐릭터의 체력이 0이 되면 게임 종료되며, 보스 몬스터 처치 시 게임 클리어

---

## 🖥️ 게임 흐름

```text
 [1. 캐릭터 생성] ──► (이름 / 스탯 / 직업 설정)
        │
        ▼
 [2. 메인 메뉴] ──┬──► [상점] (아이템 판매 및 구매)
        │           ├──► [포션 제작소] (재료를 사용하여 포션 제작)
        │           └──► [인벤토리] (소지품 확인 & 정렬)
        ▼
 [3. 던전 탐험]  ──► (1F ~ 4F 층 / 보스 방 별 진행)
        │
        ▼
 [4. 턴제 전투] ───┬──► [플레이어 턴] ──► 공격/스킬 사용 OR 포션 사용
        │          └──► [몬스터 턴] ──► 플레이어 공격
        │
        ├─────────────────────────┐
        ▼                         ▼
 [최종 보스전]             [플레이어 사망]
        │                         │
        ▼                         ▼
 [ GAME CLEAR ]            [  GAME OVER  ]
  (게임 클리어)              (게임 오버)
```
